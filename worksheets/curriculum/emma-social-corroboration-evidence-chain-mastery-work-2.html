Check Another Source — Evidence Chain

Directions: For each answer, name the source, state the exact fact you used, and say what that fact proves. Do not add details the sources do not support.

Source set 1 — Harbor Road

Source A — Town notice, June 8: “Harbor Road is closed between Pine Street and the marina because storm water damaged the culvert.”
Source B — Local newspaper, June 9: “Crews inspected the damaged culvert Tuesday morning. The town has not announced a reopening date.”
1. Write a conclusion supported by both sources. Then list the source and fact that support each part of your conclusion.
2. A student writes, “Harbor Road will reopen Friday.” Is that supported? Answer yes or no and explain exactly what the sources do or do not prove.
3. Name one genuinely new source that could check when the road reopened. State exactly what that source could show.

Source set 2 — Community Garden

Source C — Parks report, 2022: “The community garden had 24 plots in use during the 2022 season.”
Source D — Volunteer newsletter, 2024: “Six new garden plots were added before spring planting in 2024.”
4. Put the two source events in chronological order. Then write one conclusion the pair supports without assuming anything extra.
5. Can these sources prove that exactly 30 plots were in use in 2024? Explain what additional fact would be needed before making that claim.
6. Choose a new source that could check 2024 plot use. Explain why it is genuinely new evidence and what it could prove.

Evidence rule transfer

7. Rewrite this rule in your own words: “A conclusion may not claim more than the evidence supports.” Give one short example of a claim that is too strong.
8. Two sources agree that a museum opened in 1995. One student suggests using another copy of the same opening-day article to learn whether attendance increased by 2005. Explain why that is not enough and name a better new source.

Create an evidence chain

9. Use any source set above. Write three labeled lines: Fact → Source → What it proves. Then write one sentence that stays inside that evidence.
10. Imagine you want to learn one more fact that the current sources cannot answer. Write the question, name a new source you would look for, and state what evidence in that source would answer the question.
