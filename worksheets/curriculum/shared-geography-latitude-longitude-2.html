Geography · Independent Work
Directions: Latitude is first and uses N/S. Longitude is second and uses E/W. Show your hemisphere reasoning instead of guessing from the letters alone.

2. Which coordinate is impossible: 28° N, 145° E; 112° S, 40° W; or 64° N, 12° E? Explain the latitude/longitude limits.
3. Point A is 15° N, 30° E. Point B is 15° N, 80° W. What do the points share? What is different?
4. Point C is 25° S, 60° E. A student rewrites it as 60° S, 25° E. Explain why that is not the same location.
5. Write one valid coordinate in each hemisphere pair: Northern/Western, Northern/Eastern, Southern/Western, Southern/Eastern.
6. Why is a latitude/longitude grid useful to travelers, scientists, rescue teams, or mapmakers? Give one concrete example in 2–3 sentences.
