Coordinate Plane — Say the Move First

What you are learning: Translate the signs in an ordered pair into left/right/up/down movement before plotting or naming a point.

You can already plot many points correctly. The part that caused trouble was translating a sign into a direction and recognizing points that sit on an axis. Today we will separate those jobs: say the move first, then plot.

1. The first number controls horizontal movement

x is positive
→ move RIGHT

(+5, …) means 5 units right from the origin.

x is negative
← move LEFT

(−5, …) means 5 units left from the origin.

2. The second number controls vertical movement

y is positive
↑ move UP

(…, +4) means 4 units up.

y is negative
↓ move DOWN

(…, −4) means 4 units down.

3. Worked move scripts

(−4, 6): x = −4, so say “left 4.” y = +6, so say “up 6.” The point lands in Quadrant II.

(5, −3): x = +5 → “right 5.” y = −3 → “down 3.” The point lands in Quadrant IV.

(−7, −2): “left 7, down 2.” The point lands in Quadrant III.

4. Axis points use a zero test

If y = 0, there is no up/down movement, so the point is on the x-axis. Example: (−3, 0) is left 3 on the x-axis.

If x = 0, there is no left/right movement, so the point is on the y-axis. Example: (0, 5) is up 5 on the y-axis.

If both are zero, (0,0) is the origin.

5. Reverse the process

“Left 4 and down 7” means x is negative and y is negative, so the address is (−4, −7).

“On the y-axis, 6 units above the origin” means there is no horizontal move: (0, 6).

6. Check a route

Start at (0,0). Right 5 → (5,0). Up 2 → (5,2). Left 8 → (−3,2). Down 6 → (−3,−4).

Every movement changes only one coordinate. Horizontal moves change x. Vertical moves change y.

Independent-work habit: before every plotted point, write or whisper the move script: “x says ___; y says ___.” For axis points, use the zero test before naming the axis.
