Multiply or Add?

Natalie · Math · Targeted Mastery
Goal: Tell the difference between a proportional rule y = kx and an additive rule y = x + b, using constant ratios, scale factors, and the origin test.

1. Ask: “Is y always the same multiple of x?”

Proportional example
x247
y102035

Compute y ÷ x: 10 ÷ 2 = 5, 20 ÷ 4 = 5, 35 ÷ 7 = 5. The ratio is always 5, so y = 5x.

2. Equal additions are not the same as a constant ratio

Additive example
x247
y81013

Here y is always x + 6, so the rule is y = x + 6. But the ratios are 4, 2.5, and about 1.86. They are not constant, so it is not proportional.

3. Use the origin test

At x = 0: In a proportional rule y = kx, y must be 0. If the relationship starts with a fee, amount, or offset, it does not pass through (0,0).
Example: A taxi charges $4 before the trip plus $3 per mile. y = 3x + 4. At 0 miles, y = 4, so it is not proportional.

4. Scale factors multiply both coordinates

Example: If (3, 12) is on y = 4x, doubling x from 3 to 6 must also double y from 12 to 24. That is multiplicative scaling.
Trap to avoid: Seeing “both numbers increased” does not prove proportionality. Proportional relationships preserve the same multiplier, not merely the same added amount.

5. Four-question test

  1. What is y ÷ x for each nonzero pair?
  2. Is that ratio constant?
  3. Does the relationship include a starting amount?
  4. Would x = 0 give y = 0?
If the ratio is constant and the origin test passes, use y = kx.

When you can explain why y = 6x is proportional but y = x + 6 is not, open the Independent Transfer.
