Check Another Source — Build the Conclusion from Evidence

What you are learning: Compare two independent sources about the same fact and build a conclusion from what the evidence actually supports, challenges, or adds.

How this lesson works

Learn First: definitions, a four-step method, worked source comparisons, examples of independent sources, and common-error corrections. Independent Work: all required source reading, comparison, conclusions, and written responses are on the printable worksheet with the source text printed beside the questions.

1. Words you will use and the four-step method

Corroborate: compare a claim with another independent source to see what the sources support, challenge, or add.

Independent source: a genuinely different source of evidence, not the same source repeated.

StepQuestion the historian asks
1. ClaimWhat exact fact is being checked?
2. Source AWhat does this source actually say or show?
3. Source BDoes a different source support, challenge, or add to that fact?
4. ConclusionWhat can be safely said using both sources, and what is still unknown?

2. Worked example — creek crossing

Source A — student journal, Tuesday: “The creek rose over the stepping stones before lunch, so our class used the long path back.”
Source B — parks department notice: “Creek Trail crossing closed at 11:35 a.m. Tuesday because water covered the stones.”

Claim: The stepping-stone crossing was unusable before lunch.

Source A contributes: firsthand observation that the stones were covered and the class changed route.

Source B contributes: an official closure and exact time.

Strong conclusion: Both sources support that the crossing was unusable before lunch; the parks notice adds the 11:35 closure time.

Still unknown: the water depth, how long the closure lasted, and who first noticed the problem.

3. Worked source comparison — late fruit delivery

Source C — cafeteria manager email: “The delivery truck arrived after 9:00, so breakfast fruit was served late.”
Source D — delivery receipt: “Received: 9:18 a.m. — apples, bananas, milk.”
Source E — student text message: “We didn’t get fruit until later than usual.”
Source F — school calendar: “Tuesday — normal breakfast schedule.”

Best corroborating pair for a late delivery: C and D, because both directly address delivery timing and come from different records.

Detail D adds: the exact receipt time, 9:18 a.m.

What E can support: that fruit was served later than usual. By itself it does not prove the cause.

Why F is limited: it shows the normal schedule, not when the truck actually arrived.

4. Examples of genuinely new sources

Useful independent evidence might include a second eyewitness, timestamped photograph, newspaper report, official log, map made at the time, receipt, meeting minutes, or another separate record. The source choice is strongest when it could add a specific missing fact.

5. Common mistakes and corrections

Mistake: “I would check Source A again.” Correction: corroboration requires another independent source.

Mistake: “The creek was three feet deep” when neither source gives a depth. Correction: do not invent details that are not supported by evidence.

Mistake: treating an exact time from one source as if both sources gave it. Correction: separate the shared fact from the extra detail contributed by only one source.
