Check Another Source — Build the Conclusion from Evidence

This is a new class on the same prerequisite. The goal is to stop treating “check another source” as a vague instruction and use a repeatable process: name the fact, compare independent sources, say what each adds, then write only what the evidence supports.

Plan for about 50 minutes

  1. Teacher-aid method: about 8 minutes.
  2. Worked example with a new source set: about 10 minutes.
  3. Guided source comparison: about 15 minutes.
  4. Mistake detective: about 7 minutes.
  5. Independent Work: about 10 minutes.

This lesson uses a new scenario and new source set so you practice the same historical-thinking skill from a different angle.

1. Use the four-question method

StepQuestion to ask
1. ClaimWhat exact fact am I trying to check?
2. Source AWhat does this source actually say or show?
3. Source BDoes a different source support, challenge, or add to that fact?
4. ConclusionWhat can I safely say using both sources—and what can I not say?

2. Worked example — a new event

Source A — student journal, Tuesday: “The creek rose over the stepping stones before lunch, so our class used the long path back.”
Source B — parks department notice: “Creek Trail crossing closed at 11:35 a.m. Tuesday because water covered the stones.”

Claim to check: The stepping-stone crossing was unusable before lunch.

What A contributes: firsthand observation that the stones were covered and the class changed route.

What B contributes: an official closure and exact time.

Strong conclusion: Both sources support that the crossing was unusable before lunch; the parks notice adds the 11:35 closure time.

Do not add: how deep the water was, how long the closure lasted, or who first noticed it—neither source tells us those things.

3. Guided source lab

Source C — cafeteria manager email: “The delivery truck arrived after 9:00, so breakfast fruit was served late.”
Source D — delivery receipt: “Received: 9:18 a.m. — apples, bananas, milk.”
Source E — student text message: “We didn’t get fruit until later than usual.”
Source F — school calendar: “Tuesday — normal breakfast schedule.”
  1. Which two sources best corroborate the claim that the fruit delivery was late?
    CheckC and D. They are different sources and both address the delivery timing directly.
  2. What exact detail does D add that C does not?
    CheckThe exact receipt time, 9:18 a.m.
  3. Does E prove why the fruit was late?
    CheckNo. It supports that fruit was served later than usual, but it does not prove the cause by itself.
  4. Is F a useful independent source for the delivery time?
    CheckNo. It tells the normal schedule, not when the truck actually arrived.

4. Choosing a genuinely new source

If the evidence is incomplete, choose a source that could add new information, not the same source again in a different form.

Examples: a second eyewitness, a timestamped photo, a newspaper report, an official log, a map made at the time, a receipt, meeting minutes, or another independent record.

Always say what information that source could add.

5. Mistake detective

  1. A student writes: “I would check Source A again.” Explain why that is not corroboration.
  2. A student writes: “The creek was three feet deep.” Neither source gives a depth. What rule was broken?
  3. Two sources agree an event happened, but only one gives an exact time. Write a conclusion that separates the shared fact from the extra detail.
Check after all three
  1. Corroboration requires another independent source.
  2. The student invented a detail not supported by evidence.
  3. State the event as supported by both sources, then identify the exact time as information contributed by only the source that gives it.

6. Independent Work

Print the attached Independent Work page and complete it on your own. The worksheet includes the source material you need on the page. It is the independent mastery evidence for this class; there is no automatic extra mini-check afterward.

  • Name the source when you use evidence.
  • State the exact detail it contributes.
  • Use a genuinely different source when asked what to check next.
  • Do not invent details that are not in the sources.
