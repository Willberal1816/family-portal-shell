A Rule That Survives Every Point

Natalie · Math · Monday, September 28, 2026 · Learn First

What you are learning: recognize a nonzero starting amount, calculate a rate from corresponding pairs, and verify one complete rule against several data points. Read the examples, then use the separate Independent Work printable for all answers. This teaching page has no written work to turn in.

Learn the idea

A constant rate tells how much the total changes for one more unit of x. A starting value is what remains when x is zero. In y = kx + b, k is the rate, b is the start, and x and y must be defined with units. A table with a nonzero y when x=0 cannot be modeled by y=kx alone.

When x changes by more than one, divide the change in y by the SAME pair’s change in x. Do not mix a y change from one pair with an x change from another. After you write a rule, substitute every available x to see whether its predicted y matches the record.

Words that help

  • rate: the amount added to y for each 1 increase in x
  • starting value: the y amount at x=0; added once
  • verify: substitute a given x and compare the predicted y with the actual table

Worked example 1

For (2,17) and (5,29), rate = (29−17) ÷ (5−2) = 4.

Say what each number measures; that is part of the math.

Worked example 2

At x=0, y=9; at x=7, 4×7+9 = 37. Both checks matter.

A rate-only rule would fail the zero-use check because the start is not zero.
