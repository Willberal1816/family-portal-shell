Read Your Book: Show the Middle Event

Emma · Reading · Friday, November 20 · 50-minute learning block (45 minutes)

What you are learning: Identify the middle action between a problem and an outcome and prove it with page-located book evidence.

Learn First

Read your own book for 25 real minutes first.

Write the exact pages you actually read.

A sequence has an earlier event, a middle action and a later outcome.

The middle action matters because it helps explain how the later result became possible.

Do not use a page outside your logged range without correcting the range.

Important words: A page citation is the page number where your book says something. A factual event comes from your book; an inference is a careful idea you make from its evidence.

Worked models — read before independent work

Model 1: Invented example (not from your book): On page 8, a child cannot cross a stream. On page 10, the child places three boards across it. On page 12, the child reaches the other bank. The middle action (placing boards) explains the later crossing.
Model 2: A model citation reads 'On page 10, the character places three boards.' A supported inference reads 'That action may show planning because the character changed the path rather than leaping.' This reason is a guess supported by the stated action, not another fact.
Common mistake: Do not guess a page number or copy a model event as if it came from your book. Use the actual book, title, author and page range you read.

Reference for today's work

Own-book evidence organizer: Earlier problem → Middle action → Later result. Cite an actual page for each arrow. If your book contains no resolved result yet, say 'not resolved in these pages.'

Independent Work — all six questions

Every assigned question is shown on this screen and included on your four-page printable. Write on your worksheet, not on the Learn First page.

Question 1. Record the actual book title, author, first and last page read TODAY and your real active reading minutes. If you use a book with chapter or location numbers instead of ordinary pages, explain how to find each passage.

Question 2. Create a THREE-row event table: earlier problem, middle action, later result. Quote or paraphrase one exact event for each row and give a different real page number (or page range) that supports it.

Question 3. Choose your middle action. In TWO complete sentences explain how the action could change the outcome. Cite TWO exact details from pages you logged; separate the stated details from your own idea.

Question 4. Find one short exact quote that reveals the character's choice. Copy the quote with its page, then state ONE supported inference and ONE thing that the quote does not prove.

Question 5. Check every page citation you wrote. Compare each with the page range from Question 1; rewrite any out-of-range citation with the actual source or explain which part of the reading log must be corrected. Draw a small labeled sequence arrow.

Question 6. Write a FIVE-sentence independent reading summary: name the book and the day's pages; identify the first problem; state the exact middle action with a citation; describe the later result with its citation; and explain one limited cause-and-effect inference without making up the book's ending.
