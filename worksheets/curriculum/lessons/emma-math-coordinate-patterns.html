Coordinate Patterns

Emma · Math · Learn First
What you are learning: Generate ordered pairs from simple rules, graph them, notice patterns, and explain how changes in x connect to changes in y.

Learn the idea

A table can turn a rule into ordered pairs. If “y is 2 more than x,” choose x, add 2, and record (x,y). For x=-1, y=1, so the pair is (-1,1).

Graphing several pairs helps you see a pattern. If the same amount is added to x to get y, the points line up in a steady way. Connect the rule, table, ordered pairs, and graph instead of treating them as separate tasks.

Multiplication rules work similarly. If y=3x, then x-values -2,-1,0,1,2 produce y-values -6,-3,0,3,6. Negative inputs can produce negative outputs and x=0 may land at the origin.

Check a pattern by testing a point. A point fits y=x+4 only if its y-coordinate is exactly 4 greater than x. Testing is a quick way to find table or graph errors.

Words you will use

  • rule: a direction connecting one value to another
  • input: the x-value chosen first
  • output: the y-value produced by the rule
  • ordered pair: matching input/output written (x,y)
  • pattern: a relationship changing predictably

Worked examples

Example 1: y=x+2 with x=-2,0,3 gives (-2,0),(0,2),(3,5).
Example 2: y=2x with x=-2,-1,0,1,2 gives y=-4,-2,0,2,4.
Check: (3,8) fits y=x+5; (4,8) does not.

More worked examples

Teaching example: For y=x-3 and x=5, y=?
Answer / reasoning: 2.
Teaching example: Does (-2,-6) fit y=3x?
Answer / reasoning: Yes.
Teaching example: Why graph more than one point?
Answer / reasoning: Several points reveal the pattern and expose mistakes.
