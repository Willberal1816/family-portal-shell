Strong Details — Aim Every Detail at the Main Idea

What you are learning: Choose specific details that all prove the same main idea, then build them into a clear paragraph.

You can make a single sentence more vivid. Yesterday the harder part was keeping several details connected to one main idea. Today we will use a target-and-filter method.

MAIN IDEA = the target
Every supporting detail must hit this target.

1. Run every detail through two filters

  1. Relevance filter: Does this detail help prove the main idea?
  2. Specificity filter: Does it tell the reader something concrete they can picture, hear, measure, or understand?

2. Worked example — “The hike was exhausting.”

Hits the target:

“By the last hill, my legs shook and I had to stop twice to catch my breath.”

This is specific and it proves the hike was exhausting.

Misses the target:

“My water bottle was blue.”

Specific? Yes. Relevant to exhaustion? No. It does not prove the main idea.

3. Worked example — “The kitchen was busy before dinner.”

Good detail 1: Dad flipped pancakes at the stove while checking the next batch.

Good detail 2: Mom chopped fruit and called out which bowls still needed filling.

Good detail 3: The girls carried plates and cups to the table while the timer beeped.

Each detail is different, but every one proves busy before dinner.

4. Show a feeling without only naming it

Weak: “Mia was excited.”

Stronger: “Mia bounced on her toes, checked the clock again, and grinned when the car pulled into the driveway.”

The actions show the feeling. The reader does not have to rely on the word excited.

5. Build a paragraph with a detail ladder

  1. Write one clear main-idea sentence.
  2. Add Detail 1: a specific action, fact, or example.
  3. Add Detail 2: another specific piece of evidence for the same idea.
  4. Add Detail 3: one more detail that adds something new.
  5. Read each detail and ask, “Does this prove my main idea?” Remove or replace any detail that misses the target.
  6. Finish with a closing sentence only if it adds a useful ending.

6. Error check

Main idea: “Our science experiment was difficult.”

Details: “We measured the water three times because the first two amounts did not match. The thermometer kept slipping out of place. My notebook has a green cover.”

The first two details prove difficulty. The notebook color is unrelated, so it should be replaced with another detail about the experiment.

Independent-work habit: underline your main idea. Beside each supporting detail, write a tiny ✓ only after you can finish this sentence: “This proves the main idea because ___.”
