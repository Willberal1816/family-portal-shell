Coordinate Addresses — X First, Y Second

What you are learning: Read and plot an ordered pair as a two-step address: move on x first, then move on y.

The address rule

x is the hallway.
Positive x = move right.
Negative x = move left.
y is the elevator.
Positive y = move up.
Negative y = move down.
(x, y) always means: start at (0,0) → move left/right for x → then move up/down for y.

Worked example 1

Plot (-4, 3).

  1. x = -4, so move left 4.
  2. y = 3, so move up 3.
  3. Stop there. Negative x and positive y place the point in Quadrant II.

Worked example 2 — axis points

(0, 5): x is zero, so do not move left or right. Move up 5. The point is on the y-axis.

(-6, 0): move left 6, then y is zero. The point is on the x-axis.

Worked example 3 — catch a swap

(2, -5) and (-5, 2) are not the same address. For (2,-5), go right 2 then down 5. For (-5,2), go left 5 then up 2.

Three checkpoints

  1. Say the direction words before plotting.
  2. Check whether zero means the point sits on an axis.
  3. After plotting, look at the quadrant signs and ask whether they match the ordered pair.
