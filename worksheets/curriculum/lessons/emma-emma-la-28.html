Which Garden Sign Matches?

Emma · Language Arts · Monday, September 28, 2026 · Learn First

What you are learning: select the right source for each question and write a report that copies exact details without changing their meaning. Read the examples, then use the separate Independent Work printable for all answers. This teaching page has no written work to turn in.

Learn the idea

A repair log is good for dates and completed work. A visitor notice is good for where visitors should go. The sources have different jobs. Before writing, ask which author would know the fact. Copy a key word precisely: “inspected” means checked; it does not automatically mean “reopened.”

A report can combine two sources but must keep each detail attached to its real source. It should not claim every visitor was happy just because a path was open. Finish with a meaningful limit: the documents give facility records and routes, not every visitor’s private experience.

Words that help

  • source: a document or observation giving evidence
  • exact detail: a word, number or date copied without changing meaning
  • limitation: something a record does not actually establish

Worked example 1

If Source A says “April 6: three benches painted,” the accurate report is “Three benches were painted April 6.” It is NOT “the benches were built April 6.” A different verb can change the whole fact.

Worked example 2

If Source B says “use the west entrance,” that source answers an access question, not a repair date. A combined sentence names both roles: the log records the date and the notice describes access.

Use this reference while you work

Fictional classroom source packet — Which Garden Sign Matches?. Source A — caretaker log: “Pond sign installed May 10. East path sign moved May 12. Both inspected May 13.” Source B — visitor guide: “Walkers should use the east path to reach the pond.” Source C — picnic invitation.
