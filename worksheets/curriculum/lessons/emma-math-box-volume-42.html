Box Volume: Count Cubes, Then Multiply

Emma · Math · Monday, November 9, 2026 · 50 minutes · Cycle C

Today's objective: Find volume in cubic centimeters from length, width and height and explain how stacked layers build the total.

Approved background reading: Open this professional explanation if helpful. Everything needed for today's work is taught below and printed on the sheets.

Learn First: read each step

  1. A unit cube is a tiny cube one centimeter on each edge. One cubic centimeter (1 cm³) is the space taken up by that cube.
  2. A rectangular box can be counted in layers: length × width gives the number of cubes on ONE level; multiply by height to count all levels.
  3. The number of cubic units is volume. It is NOT the distance around the edge (perimeter) or the area of just one side. Always write cm³ for cubic centimeters.

See the two fully worked examples

Worked example 1: A 3 cm × 2 cm base has 3×2=6 one-centimeter cubes in each layer. At 2 cm high, two layers contain 6+6=12 cubes. Volume = 12 cm³.
Worked example 2: A box measuring 4 cm × 3 cm × 2 cm holds 4×3×2=24 cm³. A box 4×3×3 holds 36 cm³, so adding 1 cm of height increases capacity by 12 cm³.
Watch for this common error: Multiplying only 5×2 gets the BASE area, 10 cm², not the whole three-layer volume. Finish by multiplying by height.
