Graph Pattern Relationships

What you are learning

You already know how two number patterns can follow different rules. Today you will turn matching terms into ordered pairs and graph them so the relationship becomes visible.

From two patterns to ordered pairs

Pattern A starts at 2 and adds 2: 2, 4, 6, 8.

Pattern B starts at 3 and adds 4: 3, 7, 11, 15.

TermABOrdered pair (A, B)
123(2, 3)
247(4, 7)
3611(6, 11)
4815(8, 15)

The first pattern becomes the x-coordinate. The matching term from the second pattern becomes the y-coordinate.

Why the graph helps

If the points form a clear line or shape, the graph helps you see how one pattern changes compared with the other.

When B grows faster than A, the plotted points rise more quickly. The graph is another way to show the same relationship that was already in the table.

Worked example — read a rule from the pairs

Pairs: (1, 4), (2, 7), (3, 10), (4, 13).

Each time x goes up by 1, y goes up by 3. That repeated change is visible in both the table and the graph.

One rule that fits is: start at y = 4 when x = 1, then add 3 to y for each next x-value.

Coordinate reminder

x first, y second. This is only a quick reminder from your earlier coordinate work. Today’s new skill is using ordered pairs to show a relationship between two patterns.

Common mistake

Wrong: graphing the term number instead of the matching value from Pattern A when the directions say to graph (A, B).
Check: read the column headings before making each pair.

Before independent work

Build both patterns → match terms in the same row → write (A, B) → graph the points → describe what the graph shows about the relationship.
