The Package Label: What Happened First and Last

Emma · Reading · Thursday, October 29, 2026 · 45 minutes

What you will be able to do: Find the exact clue, name each response action, identify the immediate result, and separate it from a later event.

Learn First — follow these three steps

  1. Read the full passage before answering. A clue is what someone checked or observed; an action is what the people did because they needed to solve the problem.
  2. The immediate result is the first confirmed result of the actions, not a later event from that day. Use the exact time from the passage.
  3. For a clear summary, write problem → clue → action sequence → immediate result. Never add a cause that the passage does not state.

See the exact worked examples

Worked example A: 8:00 a box is missing; 8:04 a clerk checks the label; 8:08 she moves the box; 8:11 the correct recipient signs. The 8:11 signature is the immediate result, not an unrelated afternoon delivery.
Worked example B: If the text says a team 'checked the note, called the driver, then corrected the shelf card,' a summary containing only 'called the driver' leaves out two actions. Use the words first, next, then, finally.
Check this common mistake: Common mistake: 'The lost label caused the package to be delayed.' Unless the passage explicitly proves the cause, report what the workers observed and did.
