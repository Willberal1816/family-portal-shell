Scale Drawing: Plan a Campsite in Feet

Natalie | Math | Wednesday, November 25, 2026 | 50 minutes

What you are learning: Apply scale and customary length to constrained site geometry, with independent reverse checks.

Learn First

A scale is a ratio. 1 drawing inch = 4 real feet means real ft = drawing in x 4, and drawing in = real ft / 4. Show input and output units. For customary length, 1 yard = 3 feet. Audit a conversion by checking the legend, labeling both units, and reversing the calculation.

Area measures a region in square feet: length x width. Perimeter measures the boundary in feet: 2 x (length + width). To test whether a rectangular pad and path fit side by side, compare the combined widths to the site width, not only the areas.

Use the given layout assumptions, not an invented RV length. A successful sketch is not proof that a real vehicle can turn safely. Cite missing dimensions.

Two worked examples

Practice: a 3-by-2-inch drawing at 1 in = 5 ft represents 15 by 10 ft. Area = 150 sq ft; perimeter = 50 ft. Reverse-check 15 ÷ 5 = 3 drawing inches.
Practice fit: a site 18 ft wide has a 10-ft-wide pad and a 5-ft side path. Combined width 15 ft leaves 3 ft. If a path were 9 ft, the combined width 19 ft would exceed the site by 1 ft even if total area seemed adequate.

Source and materials

FICTIONAL CAMPSITE; CUSTOMARY UNITS
Scale: 1 drawing inch = 4 real feet. Site 20 ft long x 12 ft wide.
Parking pad 12 ft long x 8 ft wide. Path must be 2 yards wide.
Layout A: pad and path side by side across site width.
Layout B: pad rotated (8 ft long x 12 ft wide); path runs beyond its length.
No RV size, turning radius or actual site obstructions supplied.

All six questions

Question 1. Convert the 2-yard path to feet, then drawing inches. Show both equations and reverse-check each conversion.
Question 2. Find the site perimeter and area. Find the parking pad area and remaining area outside the pad. Explain the difference between feet and square feet.
Question 3. Test Layout A using the combined widths. Does it meet the required clearance? Calculate its exact shortfall or leftover width.
Question 4. Test Layout B: the pad is 8 ft long and 12 ft wide, with the path beyond the pad across the full width. Calculate the combined length and the leftover length. Explain whether this simplified geometry fits.
Question 5. Draw a labeled scale sketch of Layout B on the grid. Include both site and pad dimensions, the path width in drawing inches, and two reverse-checks from drawing measurements back to feet.
Question 6. Write a short design audit: compare the two layouts using at least two calculations, state two missing real-world measurements, and explain why your scale drawing does not prove an actual RV will fit.
