Controlled Friction Retest

Emma · Science · Learn First · 45 minutes
Goal: Run a fair friction comparison using a fixed release, repeated trials, averages, an outlier check, and an evidence-based claim.

Materials

  • one small object that slides safely
  • one board or firm book used as a ramp
  • two surface coverings
  • ruler or tape measure
  • books or blocks to hold one fixed ramp height

What went wrong last time

If the object is pushed harder in one trial, the result mixes surface friction with push force. Distances from 2–7 feet cannot answer the surface question when release force changes.

Repair: Do not push. Mark one start line. Place the object at the line and release it from rest every time.

Claim: In this setup, the towel produced more friction because the object traveled a much shorter average distance.

Outlier check

An outlier is a result far from the others. If trials are 31, 30, and 79 cm, stop and repeat the unusual trial after checking the setup. Do not quietly erase data.

Direction reminder

Friction acts opposite the sliding or attempted sliding. Distance is an outcome; it is not a force measurement in newtons.

Before starting: Point to the one changed variable, name at least four controls, demonstrate the no-push release, and state the measurement unit.

Independent retest

Use the companion record. Complete the design box before touching the materials. Then run three controlled trials per surface and write a precise claim using both averages.
