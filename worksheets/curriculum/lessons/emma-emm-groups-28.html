Brackets Tell the Story

Emma · Math · Monday, September 28, 2026 · Learn First

What you are learning: translate the words into a picture and expression that show what repeats and what is added once. Read the examples, then use the separate Independent Work printable for all answers. This teaching page has no written work to turn in.

Learn the idea

Read the story before choosing an operation. A repeated group means the SAME number is in each group: for 5 groups of 7, the repeated part is 5 × 7. An extra item outside the groups is added once, after multiplying. Putting it inside the parentheses says each group receives it, which changes the total.

For sharing stories, divide the shared pile first, then add any separately given amount. For every problem, first draw or label what repeats, next write the expression, and last evaluate all operations in the right order. Ask: “Does this answer fit the physical story?”

Words that help

  • group: an equal collection that repeats
  • extra: an amount given once outside the repeated groups
  • parentheses: marks that change which amounts belong together

Worked example 1

5 × 7 + 4 = 39 because four is a one-time extra.

The picture must show one group for each repeated bundle, and the extra amount apart from the bundles.

Worked example 2

If every packet has 7 cards plus 4 labels, 5 × (7+4)=55.

The brackets show what every group receives; compare the totals before deciding which story matches.
