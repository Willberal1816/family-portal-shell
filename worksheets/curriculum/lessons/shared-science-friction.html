Friction Test

Science · Learn First
What you are learning: Understand friction and set up a fair test comparing surfaces.
School word: variable = something that can change in a test

Key ideas

  • Friction is a force that resists sliding between surfaces.
  • To compare surfaces fairly, change only the surface while keeping the object, distance, and method the same.
  • Record what happened before deciding which surface had more friction.

Example

Example: Slide the same object the same way across cardboard and a towel. If you also change the object, you cannot tell whether the surface caused the difference.
