Learn First

The total price has a start fee and a cost for each hour: total = start + hourly rate × hours. A table lists paired values (hours, dollars). On a graph, hours go horizontally and dollars vertically. A tie occurs where two plans have the SAME total at the SAME hour.

Two worked examples

Worked example 1. Model: Plan X = 5 + 2h. At h=0, 1, 2, totals are $5, $7, $9. Plot (0,5), (1,7), (2,9); they lie along a line.
Worked example 2. Compare X = 5 + 2h with Y = 1 + 4h: set 5 + 2h = 1 + 4h → 4 = 2h → h=2; both cost $9. Show substitutions to prove the intersection.
Common mistake to avoid: Do not treat the starting fee as hourly price. Graph each ordered pair with hours FIRST and dollars SECOND; a graph never replaces calculation or evidence.
