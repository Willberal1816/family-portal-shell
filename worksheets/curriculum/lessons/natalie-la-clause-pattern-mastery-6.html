Clause Patterns — Build the Sentence Type

What you are learning: Decide whether each clause can stand alone, then use the clause pattern to name the sentence type.

The finish test

I = independent A complete thought that can stand alone as a sentence.

D = dependent Has a subject and verb but leaves you waiting for more. Words such as because, although, while, when, if often make a clause dependent.

Build the pattern first

I + I = compound. “Maya packed the bags, and Luis loaded the car.”

D + I or I + D = complex. “Although the road was wet, we arrived safely.”

I + I + D (or D + I + I) = compound-complex. “When the rain stopped, we left the shelter, and Dad checked the trail.”

Do not count verbs; count complete clause thoughts

“Nora washed and dried the dishes.” has two verbs but only one subject doing both actions. It is one independent clause, so the sentence is simple.

Worked check

“Because the oven was hot, I used mitts, and my sister opened the door.”

Because the oven was hot → D. I used mitts → I. my sister opened the door → I. Pattern D + I + I → compound-complex.

Independent work routine: bracket each clause → mark I or D → write the pattern → name the sentence type. Do not name the type until the pattern is written.
