Rate Plus Start

Rate Plus Start: Build the Whole Rule

Natalie · Math · Learn First · about 25 minutes

What you are learning

You are learning to build and check rules of the form y=kx+b. The rate k tells how much y changes for each 1 in x. The start b tells the value when x=0.

1. Find both parts

Worked example — bike rental: A shop charges $7 to unlock a bike and $4 per hour. Rate: $4 per hour, so k=4. Start: $7, so b=7. Rule: y=4x+7. Check x=0: y=7. Check x=3: y=4(3)+7=19.
Common error: y=x+7 forgets the $4-per-hour rate. The variable term must be 4x.

Start at x=0: b=6. From x=0 to 2, y rises 6, so the rate is 6÷2=3. From x=2 to 5, y rises 9 while x rises 3, so 9÷3=3 again. Rule: y=3x+6.

3. Proportional or rate-plus-start?

Proportional: b=0, so y=kx and (0,0) fits.
Rate plus start: b≠0, so y=kx+b. It may have a constant rate, but it is not proportional.

4. Model before independent work

  1. A delivery costs $5 plus $2 per mile: y=2x+5.
  2. A plant is 9 cm tall and grows 3 cm each week: y=3x+9.
  3. Eight dollars per ticket with no fee: y=8x; proportional because b=0.
Four-step check: circle the rate; box the start; write kx+b; substitute x=0 and one other x-value.
