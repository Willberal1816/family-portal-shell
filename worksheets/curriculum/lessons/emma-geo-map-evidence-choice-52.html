Geography: Choose the Map That Answers

Emma · Geography · Saturday November 21, 2026 · 50 minutes

What you are learning: Select a road, physical or weather map for a question, using its scale and legend.

Learn First

A road map shows routes, physical-elevation map shows terrain, and weather map shows conditions.

Two worked models

Model 1: To find streets linking a station to a library, use a road map with road names.
Model 2: To find a hill's height, use an elevation legend; weather symbols cannot prove elevation.
Check for this mistake: Use only data that a map actually displays; never invent an unmarked route.

Source and facts

  • Map A description: roads, bridge, bus stop, library, scale 1 cm = 2 km.
  • Map B: highland, river, hill heights and elevation-symbol legend.
  • Map C: rain symbols and Friday temperatures; no street names.
  • These are written map descriptions; no actual route line or distance is supplied.

Read the models, then complete your six questions using your source. Write only what the source supports.

All six independent-work questions

These exact questions are visible on screen and appear in the matching four-page PDF. Write on paper, scan all pages and finish this class in the School Portal.

Question 1. Select A, B or C for planning a bus-stop-to-library road route and name two useful features.

Question 2. Select the best map for river and hill elevations; name the relevant legend evidence.

Question 3. Select a map for rain areas. Explain why it cannot prove the shortest street route.

Question 4. Map A scale: if a real measured line were 3 cm, compute scale distance. Explain why a route cannot be measured here.

Question 5. Create a three-row table of map, purpose and one question it cannot answer.

Question 6. Write six sentences recommending appropriate maps for a driver, river group and weather reporter, with one uncertainty.
