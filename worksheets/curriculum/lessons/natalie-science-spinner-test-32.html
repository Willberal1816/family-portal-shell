Goal: identify the measured outcome and write a complete, safe two-condition fair-test plan. Plan about 50 minutes. Read this teaching page before the Independent Work section.

Learn First

Change one independent variable, measure one dependent variable with units, and keep every other important condition constant.

Worked model

Question: Does paperclip count affect fall time? IV: paperclip count (1 vs. 2). DV: fall time in seconds. Controls: same spinner, paper, drop height, release, room, timer, and measurer. Run three trials per condition and compare means.

Use this source or situation: Plan a test comparing one paperclip with two paperclips on the same paper-spinner design.
  1. 1. Name the independent variable and both conditions.
  2. 2. Name the dependent variable and its unit.
  3. 3. List five true controls.
  4. 4. Write the exact drop height and a consistent release method.
  5. 5. Describe three trials per condition, safe setup, recording, and mean calculation.
  6. 6. Write a future-tense conclusion frame that compares the two mean fall times without predicting a result.
