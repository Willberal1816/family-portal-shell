Write Directions Someone Can Follow

Emma | Language Arts | Monday, November 23, 2026 | 55 minutes

What you are learning: Write complete directions in a logical sequence using precise action verbs.

Learn First

Directions tell a reader what to do, what object to use, and when to do it. Use first, next and finally where helpful. An instruction needs enough detail to be tested.

Worked models

Weak: 'The cards by color.' Better: 'Sort the six cards into three color piles.'
Weak: 'Then put there.' Better: 'Place each pile in the tray with its matching color label.'

Check your work: Read the source labels; check calculations, evidence, or drawing guides before turning in.

Source and materials

FICTIONAL CLASSROOM SORTING TASK
Materials: 2 blue, 2 green, 2 yellow paper cards; 3 labeled trays.
Read tray labels; sort six cards; put piles in matching trays;
count each tray; record totals; return trays to shelf.
No glue, scissors or printer is required.

Answer all six questions using this teaching and source. Scan all four worksheet pages, then Finish Class in the School Portal. Ask for help when needed.

All six independent-work questions

Question 1. Rewrite the activity as six numbered complete-sentence directions in a sensible order.
Question 2. Explain which action must come before putting cards into trays and why.
Question 3. Repair these fragments: 'The blue tray.' and 'Counts in the table.' Use complete directions.
Question 4. Make a three-column Step, Action, Check table containing at least four clear steps.
Question 5. A student says scissors are necessary. Correct the claim using the provided materials list.
Question 6. Write a final classroom instruction card: title, materials, six ordered steps and a two-sentence check and cleanup note.
