Write a Model, Then Challenge It

New focus: compare two linear plans and use a counterexample to challenge an “always” claim.

Today’s structure: an 8-minute same-rate refresher, then a new comparison lesson. The full block does not repeat yesterday’s model-building sequence.

Spiral Refresher — 8 minutes

If a new story must keep the same rate 4 but use a different nonzero start, keep k = 4 and change only b.

Example: start 6, rate 4 → y = 4x + 6. Check x = 2: y = 4(2) + 6 = 14.

Learn First — 12 minutes

Two plans can trade a lower start for a faster rate.

PlanRuleStartRate
Ay = 4x + 664 per unit
By = 2x + 14142 per unit

At x=0, A is lower. At x=4, both equal 22. After x=4, B grows more slowly and becomes lower. Therefore “Plan A is always cheaper” is false.

Counterexample: To disprove an “always” rule, give one actual input where it fails and show both substitutions.

Guided Comparison — 10 minutes

Calculate both plans at x=2 and x=6. Say which is lower and explain how the start and rate create the change.

Independent Decision — 15 minutes

Complete the two-plan table, find the tie, challenge the false claim, and recommend a plan for a stated use amount.

Exit Check — 5 minutes

  • I preserved a required rate in the refresher.
  • I compared complete rules, not just rates.
  • I used a real substitution as a counterexample.
  • I tied my recommendation to a specific input.
