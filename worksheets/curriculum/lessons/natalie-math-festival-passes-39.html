Festival Passes: Tie Point and Post-Tie Proof

Natalie · Math · Wednesday, October 28, 2026 · 50 minutes

What you are learning: Model two start-plus-rate plans, find their tie point, and prove which plan is cheaper after the tie with one exact numerical counterexample.

Learn First

Write each plan as total = start fee + rate × uses. A tie occurs when the totals are equal.

A post-tie claim needs one exact input and both totals. A general statement without the two costs is not proof.

Fully worked model

Plan A = 8 + 2r; Plan B = 14 + 1r. At r = 6, both cost 20. At r = 9, A = 26 and B = 23, so B is cheaper after the tie.

Source and materials

River Festival: Blue Pass costs $6 plus $3 per ride. Gold Pass costs $18 plus $1 per ride. Use whole-number rides.

Guided model: prove the tie and the cheaper plan

Model 2 (different fees from your worksheet): Plan A costs 4 + 5r dollars for r uses. Plan B costs 16 + 2r. Set them equal: 4 + 5r = 16 + 2r, so 3r = 12 and r = 4. Check both: A = 4 + 5(4) = 24; B = 16 + 2(4) = 24. Model 3: Test r = 7 after the tie. A = 39, B = 30, so B is cheaper by $9 at seven uses. One exact numerical input with BOTH costs proves this example.

Common mistake: Deciding which plan is always cheaper from its initial fee, or presenting a post-tie opinion without substituting the ride count into both equations. The two-column worksheet table is provided: fill all rows from 0 through 12 before writing a recommendation.

Try it before printing: With the practice plans above, compute the costs for 2 uses and explain whether the same plan is cheaper before and after the tie.
