Two Number Patterns

Emma · Math · Learn First
What you are learning: Generate two number patterns from two different rules, compare how they change, and use a table to describe a relationship between the matching terms.

One rule makes one pattern

A rule tells you how to create each term. For example, “start at 3 and add 4” gives 3, 7, 11, 15, 19, ... . The amount added each time is the pattern's change.

Worked example 1: Rule A: start at 2, add 3. Rule B: start at 5, add 6.

Rule B increases by 6 while Rule A increases by 3. The gap between matching terms grows by 3 each row.

Compare matching terms

When two patterns are listed side by side, compare terms in the same row. Ask: Is one always larger? Does the difference stay the same? Does the difference grow? Can one term be described using the other?

Worked example 2: A pattern starts at 4 and adds 5. Another starts at 8 and adds 10. The second pattern is always twice the first: 4 and 8, 9 and 18, 14 and 28. That relationship can be stated as “Pattern B is 2 times Pattern A.”

Do not guess from one row

A relationship must work for every matching pair you have. If one row happens to show a difference of 5, check the other rows before claiming the difference is always 5.

Words you will use:
  • rule: the instruction that generates the pattern
  • term: one number in a pattern
  • matching terms: terms in the same row or term number
  • relationship: a statement that describes how the two patterns connect
Worked example 3 — error check: Pattern A is 6, 10, 14, 18. Pattern B is 9, 15, 21, 27. A student says “B is always 3 more than A.” That works for 6 and 9, but not for 10 and 15. The claim is false because it does not hold across the table.
