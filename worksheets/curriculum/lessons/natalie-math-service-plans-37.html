Service Plans: Starting Cost and Per-Item Rate

Natalie · Math · Monday, October 26, 2026

What you are learning: Use a table and two rules, include h = 0, compare plans, and prove a claim false with one exact counterexample.

Learn First

A total price may include a starting fee plus a constant cost for each item. If a repair service charges $12 to start and $3 per shelf, the rule is M(h) = 12 + 3h, where h is the number of shelves. When h = 0, M(0) = $12. This is the starting fee, even before any shelves are repaired.

For a second plan P(h) = 18 + 2h, compare the same value of h in both rules. M(4) = $24 and P(4) = $26, but a different h might reverse which plan costs less.

A counterexample is one specific value that proves an 'always' claim false. To refute 'Plan M is always cheaper,' find one h for which M(h) is NOT smaller. Never rely only on a sketch; show the exact two totals.

Fully worked example or model

At h = 6, M(6) = 12 + 3(6) = $30 and P(6) = 18 + 2(6) = $30. The plans tie; therefore M is NOT cheaper for every value of h.
