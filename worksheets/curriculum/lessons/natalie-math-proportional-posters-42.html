Learn First: read each step

  1. A proportional relationship is y=k×x: it costs nothing when x=0, and the ratio y/x is the same positive constant for every x>0.
  2. A fixed starting charge makes a rule like y=6+2x nonproportional: it does NOT pass through the origin (0,0), even though the total changes by $2 for each new poster.
  3. To graph a rule, use (x,y) pairs: x is number of posters (horizontal), y is cost in dollars (vertical). The point at x=0 tells whether there is a starting fee.
  4. Refresher from the last Math review: label a function input explicitly. For P(4)=3(4)=12, the input is 4 posters and output is $12.

See the two fully worked examples

Worked example 1: Printing option A charges $3 per poster, no start fee: A(0)=0; A(2)=6; A(4)=12. Every nonzero cost÷posters is $3 per poster, so it is proportional.
Worked example 2: Option B is B(x)=6+2x. At 0 posters B costs $6; B(2)=10 and B(4)=14. B is not proportional because $6 still applies at x=0. At x=6, A(6)=18 and B(6)=18; a tie does not make B proportional.
Watch for this common error: An equal increase per item means a linear rule, not necessarily a proportional rule. Check (0,0), the fixed fee, and ratios before making the claim.
