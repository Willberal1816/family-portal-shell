Proportional or Additive?

Natalie · Math · Learn First · about 35 minutes
What you are learning: Decide whether a relationship is y=kx or y=x+b, and prove the choice with ratios, scale factors, and the origin test.

1. Two structures that can look similar

Proportional: Each notebook costs $4. The rule is y=4x. Every output is made by multiplying the input by 4. The ratio y÷x is always 4, and (0,0) fits.
Additive: A game costs $4 to enter plus $1 per round. The rule is y=x+4. The difference y−x is always 4, but the ratios change. At x=0, y=4, so it does not pass through the origin.

2. Use the three-proof test

  1. Ratio: Is y÷x the same for every nonzero pair?
  2. Scale factor: If x doubles, does y double?
  3. Origin: Does x=0 force y=0?
Decision rule: All three proofs support y=kx. A fixed starting amount supports y=kx+b with b≠0.

3. Worked comparisons

Table A: (2,14), (5,35), (8,56). Ratios are 7,7,7. If x doubles, y doubles. Rule: y=7x.
Table B: (2,9), (5,12), (8,15). Each y is x+7, but ratios are 4.5, 2.4, 1.875. Rule: y=x+7; not proportional.
Graph check: A line through (0,5) may be straight, but it is not proportional because the starting value is 5.

4. Guided transfer

  1. For (1,6), (3,18), (7,42), compute every ratio and name k.
  2. For (1,6), (3,8), (7,12), identify the fixed addition and explain why no constant k works.
  3. Compare y=3x and y=3x+10 at x=0,2,5.
Common trap: Equal increases do not by themselves prove proportionality. Check the ratio and origin.
