Coordinate Plane — Use an Address and Movement Ledger

This is a new approach to the same prerequisite. Instead of memorizing quadrants first, treat every ordered pair as an address built from two separate moves.

Class plan

Learn First: coordinate addresses, a horizontal/vertical movement ledger, axis checkpoints, and reverse checks. Independent Work: fresh plotting, translation, axis, error-analysis, and route problems on printed coordinate planes.

1. An ordered pair is a two-part address

First number = x address = horizontal move.

Second number = y address = vertical move.

DirectionCoordinate effect
Right / Eastpositive x
Left / Westnegative x
Up / Northpositive y
Down / Southnegative y

Example: “7 west, 2 north” becomes x = -7, y = 2, so the address is (-7, 2).

2. Use a movement ledger

Keep horizontal and vertical movement in separate columns. This prevents x/y order from switching.

Movex changey change
4 right+40
3 down0-3
Final address(4,-3)

Notice that the route can happen in any order, but the final address is always written x first, y second.

3. Axis checkpoint

If one coordinate is zero, stop before naming a quadrant.

  • (0,6): no horizontal movement → on the y-axis.
  • (-5,0): no vertical movement → on the x-axis.
  • (0,0): the origin.

Only points with both coordinates nonzero are inside quadrants.

4. Reverse-check the address

After writing a coordinate, read it backward into movement words.

(-3,8) must read “3 left and 8 up.” If your original directions were different, your ordered pair needs repair.

(6,-4) must read “6 right and 4 down.”

5. Quadrants become a sign check

Once the address is correct, the quadrant is just the sign pattern:

  • I = (+,+)
  • II = (-,+)
  • III = (-,-)
  • IV = (+,-)

Example: (-7,2) is Quadrant II because x is negative and y is positive.

6. Route example

Start at (-2,1). Move 5 right, then 4 down.

Stepxy
Start-21

-4 down3-3

Final address: (3,-3), Quadrant IV. Reverse-check: 3 right and 3 down.

7. Common errors

Directions: “6 down and 2 right” does not become (-6,2). Sort by axis: right is x = +2; down is y = -6; answer (2,-6).

Axis: (0,-4) is not Quadrant III or IV. x = 0 means y-axis.

Route: adding a down move to x is an axis mix-up. Down always changes y.

8. Independent mastery evidence

The printable uses new directions, new points, and new routes. Use the ledger whenever a problem has movement words. Every plotting task already includes a coordinate plane.
