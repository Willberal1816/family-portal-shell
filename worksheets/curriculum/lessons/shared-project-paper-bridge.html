Paper Bridge Challenge

Emma + Natalie · Project · Learn First
What you are learning: Use the engineering design cycle to plan, build, test, analyze, and improve a paper bridge under clear constraints.

Learn the idea

Engineering is not “build once and hope.” Engineers define a problem, work within constraints, create a design, test it, examine failure, and improve the next version. A failed test is useful when you record what happened.

Your challenge is to span a gap using limited paper and tape while supporting as much load as possible. Flat paper bends easily. Folding changes shape and can increase stiffness. Beams, tubes, pleats, triangles, and layers distribute forces differently.

Before building, sketch at least two ideas and predict where each may bend. Choose one for Version 1. Add load gradually in the same place so comparisons are fair. Record the maximum load before major failure.

Redesign one feature based on evidence rather than randomly changing everything. If the center sags, reinforce or reshape the span; if the ends slip, improve how it rests on supports. Connect the design change to measured performance.

Words you will use

  • constraint: a limit the design must follow
  • prototype: a testable version of a design
  • load: weight or force the bridge supports
  • failure point: where/how the structure stops meeting the goal
  • iteration: a new version changed using prior-test information

Worked examples

Shape: accordion folds create ridges that can resist bending better than a flat sheet.
Fair test: same gap, material limit, load placement, and load steps for Version 1 and 2.
Useful failure note: “The center folded sharply at 18 washers” guides redesign better than “It broke.”

More worked examples

Teaching example: Why sketch before building?
Answer / reasoning: To compare ideas and create a testable plan.
Teaching example: Why change one main feature in Version 2?
Answer / reasoning: So performance differences can be linked to a design decision.
Teaching example: What makes the version comparison fair?
Answer / reasoning: Keep gap, materials, load placement, and testing method consistent.
