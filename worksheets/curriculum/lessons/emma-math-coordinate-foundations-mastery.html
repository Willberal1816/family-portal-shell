Coordinate Plane — Make the Foundations Automatic

Today stays on coordinate-plane foundations. You are not moving to a new idea yet. The goal is to make (x, y), direction signs, axes, and quadrants feel automatic so the next lesson has a solid base.

Your plan for about 50 minutes

  1. Learn and review: about 10 minutes.
  2. Worked examples: about 10 minutes.
  3. Guided practice: about 12 minutes.
  4. Mistake detective + independent warm-up: about 8 minutes.
  5. Mastery check: about 10 minutes, done on your own.

Do not rush to fill time. Work carefully and use the check-your-answer boxes only after you have tried each problem.

1. Build the map in your head

An ordered pair is always written (x, y).

x comes first = horizontal = left/right.

y comes second = vertical = up/down.

  • Right gives a positive x.
  • Left gives a negative x.
  • Up gives a positive y.
  • Down gives a negative y.

The center point (0, 0) is the origin. If x is 0, the point is on the y-axis. If y is 0, the point is on the x-axis.

Quadrants follow the signs:

  • Quadrant I: (+, +)
  • Quadrant II: (-, +)
  • Quadrant III: (-, -)
  • Quadrant IV: (+, -)

2. Watch three complete examples

Example A — directions to a coordinate

“4 units left and 3 units up.”

  1. Left/right is x. Left means negative, so x = -4.
  2. Up/down is y. Up means positive, so y = 3.
  3. Write x first, y second: (-4, 3).
  4. The signs are (-, +), so this is Quadrant II.

Example B — coordinate to directions

Point (5, -2).

  1. x = 5 means move 5 right.
  2. y = -2 means move 2 down.
  3. The signs are (+, -), so the point is in Quadrant IV.

Example C — a point on an axis

Point (-3, 0).

  1. x = -3 means 3 left.
  2. y = 0 means no up/down movement.
  3. Because y is 0, the point lies on the x-axis. It is not in a quadrant.

3. Guided practice — try first, then check

Use scratch paper. Write each answer before opening the answer box.

  1. Move 6 right and 2 up. Write the coordinate and quadrant.
    Check after you try(6, 2), Quadrant I. Right gives +x; up gives +y.
  2. Move 5 left and 4 down. Write the coordinate and quadrant.
    Check after you try(-5, -4), Quadrant III.
  3. Point (2, -7): write the two moves and quadrant.
    Check after you try2 right, 7 down; Quadrant IV.
  4. Point (-8, 3): write the two moves and quadrant.
    Check after you try8 left, 3 up; Quadrant II.
  5. Point (0, -6): name where the point lies.
    Check after you tryy-axis. x is 0, so the point is on the vertical axis.
  6. Point (7, 0): name where the point lies.
    Check after you tryx-axis. y is 0, so the point is on the horizontal axis.

4. Mistake detective

For each one, write what the student did wrong and then write the correct answer.

  1. A student says “3 left and 5 up” is (5, -3).
    Check after you explain itThe student switched x and y and also attached the signs to the wrong movements. Correct: (-3, 5).
  2. A student says point (-4, -2) is in Quadrant II.
    Check after you explain itBoth coordinates are negative, so the point is in Quadrant III.
  3. A student says (0, 5) is in Quadrant I.
    Check after you explain itx is 0, so the point is on the y-axis, not in a quadrant.

6. Now do the mastery check

The mastery check is the final independent evidence. Do not use the answer boxes above while you take it.

  1. For every ordered pair, say to yourself: x first — left/right; y second — up/down.
  2. Check the sign before writing the coordinate.
  3. If one coordinate is 0, name the correct axis instead of a quadrant.
  4. Complete the attached mastery-check sheet on your own.

If the order, signs, axes, and quadrants are secure, the next coordinate-plane lesson can move forward.
