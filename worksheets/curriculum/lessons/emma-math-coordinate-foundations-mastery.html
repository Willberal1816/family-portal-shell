Coordinate Plane — Make the Foundations Automatic

This lesson reteaches the same prerequisite with a visual approach. The goal is to make (x, y), direction signs, axes, and quadrants automatic.

2. Build the coordinate map

x comes first = horizontal = left/right.

y comes second = vertical = up/down.

  • Right → positive x.
  • Left → negative x.
  • Up → positive y.
  • Down → negative y.

The origin is (0,0). If x = 0, the point is on the y-axis. If y = 0, the point is on the x-axis. Axis points are not inside a quadrant.

Quadrants: I (+,+), II (-,+), III (-,-), IV (+,-).

3. Worked examples

Directions → point: 4 left and 3 up gives x = -4, y = 3, so the point is (-4,3) in Quadrant II.

Point → directions: (5,-2) means 5 right, 2 down, so it is in Quadrant IV.

Axis point: (-3,0) means 3 left and no vertical movement, so the point lies on the x-axis.

Another example: 6 right and 2 up gives (6,2), Quadrant I.

Another example: (0,-6) lies on the y-axis because x is 0.

4. Common mistakes and corrections

Mistake: “3 left and 5 up” is written as (5,-3). Correction: x/y were switched and the signs were attached to the wrong movement; the correct point is (-3,5).

Mistake: (-4,-2) is called Quadrant II. Correction: (-,-) is Quadrant III.

Mistake: (0,5) is called Quadrant I. Correction: x = 0 places the point on the y-axis, not inside a quadrant.
