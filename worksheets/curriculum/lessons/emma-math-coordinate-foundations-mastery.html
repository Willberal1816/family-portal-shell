Coordinate Plane — Make the Foundations Automatic

This is a new class on the same prerequisite. The goal is to make (x, y), direction signs, axes, and quadrants automatic before moving into harder coordinate problems.

2. Build the map in your head

x comes first = horizontal = left/right.

y comes second = vertical = up/down.

  • Right → positive x.
  • Left → negative x.
  • Up → positive y.
  • Down → negative y.

The origin is (0,0). If x=0, the point is on the y-axis. If y=0, the point is on the x-axis. Axis points are not inside a quadrant.

Quadrants: I (+,+), II (-,+), III (-,-), IV (+,-).

3. Worked examples

Directions → point

“4 left and 3 up” → x=-4, y=3 → (-4,3) → Quadrant II.

Point → directions

(5,-2) → 5 right, 2 down → Quadrant IV.

Axis point

(-3,0) → 3 left, no vertical movement → x-axis.

4. Guided practice — try first

  1. 6 right, 2 up: coordinate + quadrant.
    Check(6,2), Quadrant I.
  2. 5 left, 4 down: coordinate + quadrant.
    Check(-5,-4), Quadrant III.
  3. (2,-7): movements + quadrant.
    Check2 right, 7 down; Quadrant IV.
  4. (-8,3): movements + quadrant.
    Check8 left, 3 up; Quadrant II.
  5. (0,-6): exact location.
    Checky-axis.
  6. (7,0): exact location.
    Checkx-axis.

5. Mistake detective

  1. A student says “3 left and 5 up” is (5,-3). Explain both errors, then correct it.
  2. A student says (-4,-2) is Quadrant II. Use the sign pattern to correct the quadrant.
  3. A student says (0,5) is Quadrant I. Explain why zero changes the answer.
Check after all three
  1. x/y were switched and signs attached to the wrong movements; correct is (-3,5).
  2. (-, -) is Quadrant III.
  3. x=0 puts the point on the y-axis, not in a quadrant.
