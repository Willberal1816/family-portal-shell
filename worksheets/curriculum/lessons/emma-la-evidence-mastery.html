Story Clues — Match the Evidence to the Idea

Today stays on using clues from a passage. The goal is to make the explanation match the exact evidence before moving to a new Language Arts skill.

1. Start with the idea

An inference is an idea you figure out from clues. Write the inference clearly first.

2. Choose the strongest clue

Worked example: Inference: “Maya is nervous.” Clues: Maya checks the clock three times, taps her foot, and smiles at her friend.

The strongest clue is “Maya checks the clock three times” because repeated checking directly shows worry or impatience. The smile is weaker because it could mean many things.

3. Make every part match

If the question asks for two parts, answer both parts. If it asks which clue is strongest, name the clue and say why it supports the inference better than the other clues.

If you write your own details, make sure the feeling or idea a reader should infer is the same one your details actually show.

Now do your mastery check

  1. Write the inference.
  2. Name the exact clue.
  3. Explain in one sentence how that clue supports the inference.
  4. Answer every numbered part before moving on.

Use the short follow-up attached to this class. If the evidence and explanation match, the next Language Arts skill can move forward.
