Rule Detective: Rate, Start, Check

Natalie · Math · 25 minutes Learn First + 25 minutes independent evidence

What you are learning

You are learning to recover the whole rule y=kx+b from a story or table. You will prove the rate with two change calculations, read the start at x=0, and check the completed rule.

Use the four-box method

  1. Rate k: compute change in y ÷ change in x twice.
  2. Start b: read the y-value when x=0.
  3. Whole rule: write y=kx+b. Never replace b with k or drop either part.
  4. Check: substitute one nonzero x-value. Your result must match the story or table.
Worked table:
x025
y71527

First rate check: (15-7)÷(2-0)=8÷2=4. Second rate check: (27-15)÷(5-2)=12÷3=4. So k=4. At x=0, y=7, so b=7. Whole rule: y=4x+7. Check x=5: 4(5)+7=27.

Three error types to catch:
  • y=x+9 drops the rate when a story says $2 per mile.
  • y=2x+2 repeats the rate instead of using the $9 start.
  • A table value that does not satisfy the written rule means the rule or arithmetic must be repaired.

Proportional test

A rule is proportional only when b=0; then it passes through (0,0). A constant rate alone is not enough.

Quick contrast: y=6x is proportional. y=6x+11 is not, because its start is 11.

Before you submit

  1. Did I write a number for k?
  2. Did I write a number for b?
  3. Does my rule contain both numbers?
  4. Did I show two change calculations when a table was given?
  5. Did I check x=0 and one nonzero value?
  6. Did I answer every part, including the real-world situation?
