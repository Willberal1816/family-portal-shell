Goal: solve where two linear rules are equal and prove the intersection with substitution. Plan about 50 minutes. Read this teaching page before the Independent Work section.

Learn First

At an intersection, the same input produces the same output in both rules. Solve the equality, then substitute into both original rules.

Worked model

A(x)=3x+4 and B(x)=x+20. Set 3x+4=x+20; subtract x and 4: 2x=16, so x=8. A(8)=28 and B(8)=28, so (8,28) is the intersection.
