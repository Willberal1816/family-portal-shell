Learn First

A grid address names the COLUMN LETTER first, then the ROW NUMBER: B3 means column B, row 3. Moving from A1 to D1 changes the letter but NOT the row, so it is due EAST. Moving both a letter and row can be diagonal. A simple classroom grid is NOT an accurate real-world hiking navigation map.

Worked example

From A2 to C2: start in column A, row 2; move TWO squares EAST to C2. From B1 to B3: the column stays B and you move TWO squares NORTH. Never say 'northeast' when only one coordinate changes.
