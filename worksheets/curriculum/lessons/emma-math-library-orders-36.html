Learn First

A total with several identical bundles has two stages. First find the cost INSIDE one bundle, then multiply by the number of bundles. Only after that add a one-time charge. bundle count × (cost of each item inside one bundle) + one-time fee. A check can use repeated addition of each bundle price.

Two worked examples

Worked example 1. Three identical book boxes each hold one $4 notebook and two $2 folders, plus one $5 delivery fee. One box costs $4 + $2 + $2 = $8. All costs: 3 × (4 + 2 + 2) + 5 = $29. Check: $8 + $8 + $8 + $5 = $29.
Worked example 2. Four craft packs each contain $3 of paper and $2 of tape, plus a $6 single order fee. 4 × (3 + 2) + 6 = 4 × 5 + 6 = $26. Mistake to avoid: putting the $6 fee inside every pack would wrongly add it four times.
Common mistake to avoid: Write the repaired expression whenever you explain an incorrect one. Evaluate parentheses, then multiplication, then the once-only addition. Label dollars.
