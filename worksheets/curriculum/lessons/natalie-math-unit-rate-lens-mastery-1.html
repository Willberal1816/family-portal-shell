Unit Rates — Name the Per-1 Unit

What you are learning: Choose the correct division direction by naming the unit you want per 1, test proportional relationships with a constant rate, and recognize when a starting fee makes a relationship non-proportional.

Yesterday you could calculate many rates, but two ideas were inconsistent: which quantity belongs on top and what makes a relationship proportional. Today use the unit label first. Do not divide until the words after “per” are clear.

1. Start with the label, not the numbers

Step A: Circle the unit you want for the answer.

Step B: Say the full label: miles per hour, dollars per pound, pages per minute.

Step C: Put the first named unit on top and the “per” unit on the bottom.

Example: 42 miles in 3.5 hours. The question asks for miles per hour.
miles ÷ hours = 42 ÷ 3.5 = 12 miles per hour.
If you divide hours ÷ miles, the label would be hours per mile, which answers a different question.

2. Two correct rates can describe the same situation

A runner travels 1 mile in 8 minutes.
Miles per minute: 1 ÷ 8 = 0.125 mi/min.
Minutes per mile: 8 ÷ 1 = 8 min/mi.
Both are valid, but you must use the same orientation when comparing runners.
Quick check: If the question says “dollars per pound,” which division matches the label?
A. pounds ÷ dollars    B. dollars ÷ pounds
Answer: B.

3. Proportional means one constant multiplier

y ÷ x333

The same unit rate, 3, appears every time. The rule is y = 3x. This is proportional.

Do not use “both numbers increase” as the test. Many non-proportional relationships increase. The test is whether the same multiplicative rate connects the quantities every time.

4. The origin test catches starting fees

A taxi charges $4 to start + $2 per mile.

At 0 miles the cost is already $4. A proportional relationship of the form y = kx must pass through (0,0). The starting fee breaks simple proportionality.

5. Three-part self-check

  1. Label check: What exact unit should the answer have?
  2. Rate check: Did I divide in the direction that produces that unit?
  3. Proportion check: Is the same multiplier/rate used throughout, and would 0 of the first quantity give 0 of the second?
Independent work rule: Before each calculation, write the requested label as “___ per ___.” For every table, compute the same orientation each time and write the equation when it is proportional.
