Compare Two Linear Models and Prove the Rule

Natalie · Math · Wednesday, October 14, 2026 · Learn First

Goal: compare two linear models, preserve the exact starting value, and prove conclusions with complete substitution. Read this teaching page before opening the separate Independent Work printable.

Worked model

Plan A costs $12 to start plus $3 per hour: A(h)=3h+12. Plan B costs $6 to start plus $5 per hour: B(h)=5h+6. At h=3, A=21 and B=21, so the plans tie. A complete proof shows the rule, substitution, arithmetic, and units.

Reliable method

  1. Read the rate and the starting value separately.
  2. Write each rule in the form y = rate × input + start.
  3. Substitute the same input into both complete rules.
  4. Use a table or equation to find the tie, then verify it in both rules.
