Reading: Put Events in Page Order

Emma · Reading · Saturday November 21, 2026 · 45 minutes

What you are learning: Cite actual pages for three events; distinguish facts and guesses.

Learn First

An event happens in a story. A page citation identifies where. An inference is a supported guess.

Two worked models

Model 1: FICTIONAL model: A key appears p.8; a door opens p.10; a note appears p.12. Order: 8, 10, 12.
Model 2: Hearing a creak is a fact if stated; claiming it came from an attic is a guess unless the text says so.
Check for this mistake: Never invent pages, events or quotations outside today's real reading.

Source and facts

  • Read your OWN current book for 25 active minutes.
  • Use only actual page numbers and events in your read range.
  • The example above is fictional and is NOT evidence from your book.

Read the models, then complete your six questions using your source. Write only what the source supports.

All six independent-work questions

These exact questions are visible on screen and appear in the matching four-page PDF. Write on paper, scan all pages and finish this class in the School Portal.

Question 1. Write book title, first and last page, and 25 active reading minutes; name one confirmed early event.

Question 2. List three real events, each with a page and one exact story detail, in an event-page-detail table.

Question 3. Order the three events using arrows and explain in two sentences why the middle event changes the situation.

Question 4. Cite one clue, state what is actually written, make one careful inference, and identify what it does not prove.

Question 5. Audit the order against the three pages; correct any error and explain why two events cannot be reversed.

Question 6. Write five sentences about the page-cited event sequence, ending with one unanswered question at your stopping page.
