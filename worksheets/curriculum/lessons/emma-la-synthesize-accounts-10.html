Synthesize Two Accounts

Emma · Language Arts · Learn First
Goal: Combine trustworthy details from two accounts into one neutral explanation without pretending the accounts say exactly the same thing.

1. Start with the shared facts

Write what both accounts support. These facts become the backbone of your synthesis.

2. Add one useful difference from each account

Ask what each writer saw, emphasized, or was in a position to know. A difference can add information instead of creating a contradiction.

Model: Both accounts say a storm closed the bridge at noon. The reporter adds the official safety reason. A nearby resident adds how the closure affected people trying to get home. A synthesis can include all three details because each source contributes a different piece.

3. Use neutral source language

Use phrases such as “Account A reports…”, “Account B emphasizes…”, and “Together, the accounts show…”. Avoid calling a writer wrong unless the evidence actually proves a factual conflict.

Synthesis frame: Shared fact → useful detail from Account A → useful detail from Account B → sentence explaining how the details create a fuller picture.

4. Choose exact evidence

Do not say “they were different.” Name the exact detail from each account. Yesterday you did this accurately; today the new skill is combining those details into one coherent explanation.

Open the Independent Work when you can explain the difference between comparing two accounts and synthesizing them.
