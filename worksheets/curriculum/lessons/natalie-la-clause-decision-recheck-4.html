Clause Decision Recheck

Use this decision ladder

1. Find each whole clause. A clause has its own subject and verb.

2. Read that whole clause by itself. If it makes a complete thought, mark I. If it leaves you waiting for more, mark D.

3. Name the pattern. I + I = compound. D + I or I + D = complex. D + I + I (or I + I + D) = compound-complex.

Worked example: While the soup cooled, Maya set the table.

While the soup cooled → “While…” leaves you waiting for more → D.

Maya set the table → complete thought → I.

Pattern D + I → complex.

Before you print

The recheck uses new sentences. For every item, prove the I/D label with the stand-alone test before you name the sentence type.
