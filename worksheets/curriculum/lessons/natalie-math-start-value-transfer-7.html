Rate and Starting Value: New Cases

Natalie · Math · Friday, September 25, 2026 · Learn First

What you are learning: use the same two coordinate pairs for rate, find the starting value, and test the entire rule. Read these worked examples before opening the separate Independent Work page. There is no written work to complete on this teaching page.

Read a table correctly

A taxi starts with a $7 booking charge and costs $3 for each mile. When x is miles and y is dollars, the rule is y = 3x + 7. At 0 miles the cost is $7, so the starting value is 7. At 4 miles: 3 × 4 + 7 = $19.

Pair before subtracting

For points (0,5), (2,13), (5,25), use the same points in numerator and denominator: (13 − 5) ÷ (2 − 0) = 8 ÷ 2 = 4. Another pair: (25 − 13) ÷ (5 − 2) = 12 ÷ 3 = 4. Since x = 0 gives 5, the whole rule is y = 4x + 5. Verify x = 5: 4 × 5 + 5 = 25.

The missing-start mistake

Those points do not fit y = 4x. At x = 0 that wrong rule gives zero, but the table says five. The starting value b stays in the rule. A proportional rule has b = 0 and passes through (0,0); a rate-plus-start rule does not.

What proof looks like

Write all parts: k = 4 units of y per one x; b = 5 units of y at x = 0; rule y = 4x + 5; substitution at each requested x. State what each number measures, not merely k=4 and b=5.
