Graph Pattern Relationships

Emma · Math · Independent Work
Directions: Build each pair of patterns, form ordered pairs from matching terms, and graph or describe the relationship. Use the first pattern for x and the second pattern for y.
1. Pattern A starts at 1 and adds 2. Pattern B starts at 3 and adds 4. Complete five matching terms and write the ordered pairs.

2. Plot those five points on a coordinate plane. Then describe what happens to y each time x increases by 2.
3. Pattern A is 2, 5, 8, 11. Pattern B is 4, 10, 16, 22. Write the four ordered pairs and explain the relationship between x and y.
4. A graph contains (3,7), (5,11), (7,15), and (9,19). What pattern rule could generate the x-values? What rule could generate the y-values? Explain how you know.
5. Error check: A student pairs the third term of Pattern A with the fourth term of Pattern B. Explain why this changes the meaning of the graph and correct the method.
6. Create two number-pattern rules, list five matching terms, and write the ordered pairs you would graph. Describe one relationship your graph would show.
