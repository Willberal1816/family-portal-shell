Proportional or Additive?

Natalie · Independent transfer · 20–25 minutes
For each item, show the test you used. Do not decide from appearance alone.
1. Table: (2,10), (4,20), (7,35). Find all y÷x ratios, write the rule, and decide proportional or not.
2. Table: (2,10), (4,12), (7,15). Find the fixed change, test two ratios, write the rule, and decide proportional or not.
3. A taxi charges $6 before the trip plus $3 per mile. Write the rule, give the value at 0 miles, and explain why it is or is not proportional.
4. Four movie tickets cost $46. Eight tickets cost $92. Twelve tickets cost $138. Find the per-ticket rate and use a scale-factor check.
5. Compare Rule A: y=8x and Rule B: y=8x+12. Complete x=0,2,5 for both rules and explain the structural difference.
6. Error analysis: “The pairs (1,5), (2,6), (3,7) are proportional because both columns rise by 1.” Correct the reasoning with ratios and a rule.
7. Create one proportional table and one additive table using the same three x-values. Label each rule and prove each classification.
