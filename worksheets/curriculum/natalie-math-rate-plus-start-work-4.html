Rate Plus Start

Natalie · Independent evidence · 20–25 minutes
For each item: identify the rate k, identify the start b, write the complete rule, and check it with a value. Do not reuse examples from the lesson.
1. A music service charges $8 each month plus a one-time $15 setup fee. Write the rule, find the cost at 0 months and 4 months, and state whether it is proportional.
2. Complete the table for y=5x+3 at x=0, 2, and 6. Label the rate and start.
3. Table: (0,4), (3,10), (7,18). Use two change calculations to find the rate, then write and check the rule.
4. Table: (0,0), (4,28), (9,63). Write the rule and prove whether it is proportional.
5. Correct this rule: “A taxi charges $9 to start and $2 per mile, so y=x+9.” Name the missing part, write the correct rule, and check 5 miles.
6. Compare A: y=6x and B: y=6x+11. Make both tables for x=0, 1, and 4. Explain exactly why only one is proportional.
7. Create a new real-world situation with a rate of your choice and a nonzero start. Write its rule and calculate two values, including x=0.
