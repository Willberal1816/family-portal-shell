Paper Bridge Challenge

Emma + Natalie · Project
Directions: Suggested materials: paper, limited tape, two equal supports, ruler, and repeatable loads such as coins or washers. Parent approves setup. For reasoning questions, name the design choice or claim, give the measurement/observation that supports it, and write one sentence connecting the evidence to the claim.

Define and plan

1. Write exact constraints: gap width, sheets allowed, tape limit, and load type.
2. Sketch Design A and B. Label folds/shapes and predicted weak points.
3. Choose Version 1. Record (1) which design you chose, (2) one design reason for the choice, and (3) your predicted maximum load with units/items.

Build Version 1

4. Build the first prototype and record any necessary construction change.
5. Add load gradually. Record successful loads and first major-failure load.
6. Record where the first major problem began and name the failure type: bending, twisting, slipping, tearing, or collapse. Add a labeled sketch if it makes the location clearer.

Redesign

7. Choose one main Version 2 change based on failure evidence. State reason before rebuilding.
8. Build Version 2 with the same material constraints.
9. Test Version 2 with same gap, placement, and load steps. Record results.

Compare

10. Compare maximum loads. By how much did performance change?
11. Was the redesign successful? Write three labeled parts: Claim (yes, partly, or no), Evidence (the Version 1 and Version 2 maximum loads), and Reasoning (one sentence explaining how those measurements support your claim).
12. Emma: Draw strongest part of final bridge and label what the shape helped it do.
13. Natalie: Calculate load supported per sheet for each version if possible. Does efficiency change your judgment?
14. Name one change you would test in Version 3. Then name one specific Version 1 or Version 2 result that led you to that change.
