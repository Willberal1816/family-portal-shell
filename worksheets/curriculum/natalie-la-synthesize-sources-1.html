Two-Source Synthesis

Natalie · Language Arts · 55 minutes including Learn First

Topic: A town converted an unused lot into a community garden.

Source A — project record: Work began March 12. Volunteers built 18 beds, installed two rain barrels, and opened the garden May 6.

Source B — resident interview: A nearby resident says the lot now feels welcoming, children visit after school, and neighbors share vegetables, but watering can be difficult during dry weeks.

1. State each source’s purpose and strongest kind of evidence.
2. Write one claim supported by both sources. Cite one detail from each and explain the connection.
3. What can Source A establish that Source B cannot? What can Source B add that Source A cannot?
4. Identify one limitation in each source.
5. Write a neutral 5–6 sentence synthesis. Include the claim, evidence from both sources, and one limitation.
