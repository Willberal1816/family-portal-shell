Maps as Historical Evidence

Shared Social Studies

Mini Lesson

Maps are sources too. A map can show location, distance, boundaries, movement, or change, but you still need to ask who made it and for what purpose.

Practice

1. Name two kinds of information a historical map could show.
2. What might a map leave out even if everything shown is accurate?
3. Why would comparing an old map with a modern map be useful?
4. A migration route crosses several rivers and mountains. What question could the map help you answer?
5. Write one context question you should ask about the map creator.
