Which Evidence Is Strong Enough?

Natalie · Independent Work · evaluate, rank, explain

Name ____________________ Date __________

Claim: The new lunch line moved students faster.

Source A — Student comment: “The line felt much shorter on Tuesday.”

Source B — Cafeteria timing log: Monday before the change: 14 minutes for 40 students. Tuesday after the change: 9 minutes for 42 students.

Source C — Menu: Tuesday served tacos, fruit, and milk.

  1. Rate each source for relevance: strong, partial, or weak. Explain each rating.
  2. Which source has the strongest access to exact wait time? Why?
  3. Write one careful claim supported by Sources A and B together.
  1. Explain why Source C does not support the speed claim, even though it describes Tuesday.
  2. Name one limitation of the timing log.
  3. What additional evidence would make the conclusion stronger?
  4. A writer says, “The new line system always works better.” Revise this overclaim using the available evidence.
  5. Write a 5-sentence evaluation: claim, best evidence, reasoning link, weaker evidence, limitation.
