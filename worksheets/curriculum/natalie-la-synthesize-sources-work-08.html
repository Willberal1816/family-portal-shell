Synthesize Evidence Across Sources

Directions: Use both sources. When a question asks for the best source, explain why its access or format makes it stronger for that exact claim. Final response: exactly 4–5 sentences.
Source A — project record: “Trail restoration began April 12. The east section reopened April 28 after crews replaced two damaged boardwalk sections.”
Source B — interview with a frequent walker: “For a couple of weeks I used the west loop because the east side was closed. When it reopened near the end of April, the new boards felt much steadier after rain.”
1. Which source is strongest for the exact starting date? Explain why.
2. Which source is strongest for how the closure affected a regular visitor? Explain why.
3. Name one fact or conclusion both sources support.
4. Identify one detail that appears only in Source A and one that appears only in Source B.
5. Write a neutral synthesis in exactly 4–5 sentences. Use evidence from both sources and do not claim anything the sources cannot prove.
6. Write one question the two sources still cannot answer. Explain what kind of source would answer it best.
