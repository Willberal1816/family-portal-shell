Coordinate Patterns

Emma · Math

Mini Lesson

A table of x- and y-values can describe a pattern. Plotting the ordered pairs lets you see how the two quantities change together.

Practice

1. Complete the pattern if y=x+2 for x=-2,-1,0,1,2. Write all five ordered pairs.
2. Complete the pattern if y=2x for x=-2,-1,0,1,2.
3. Which pattern changes faster as x increases: y=x+2 or y=2x? Explain from the table.
4. Plot three points from one pattern and describe what you notice.
5. Write a rule for the pairs (0,1), (1,3), (2,5), (3,7).
