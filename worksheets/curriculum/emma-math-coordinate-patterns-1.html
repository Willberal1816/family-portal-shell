Coordinate Patterns

Emma · Math
Directions: For each rule, make a table before graphing. Label points clearly. When asked to describe or explain a pattern, write one sentence naming exactly how y changes when x changes.

Build pairs

1. Rule y=x+3. Find y for x=-3,-1,0,2,5 and list pairs.
2. Rule y=2x. Find y for x=-3,-1,0,1,4.
3. Rule y=x-4. Find three points including one negative y.

Graph

4. Graph the five points from y=x+3. Then write one sentence describing how y changes each time x increases by 1.
5. Graph the five points from y=2x. Then write one sentence comparing how much y changes for each +1 in x with the y=x+3 graph.

Check and correct

6. Which fit y=x+2: (1,3),(2,5),(-2,0),(4,6)? Show checks.
7. A y=3x table lists (2,5). Substitute x=2 into the rule, show the check, and write the corrected ordered pair.
8. Compare (2,-4) with the swapped point (-4,2): name the quadrant of each point, then write one sentence explaining what changed when x and y switched places.

Apply

9. A game awards 4 points/token. Let x=tokens, y=points. Table 0–5 and graph.
10. Create a rule using x plus/minus a number or a whole-number multiple. Give five pairs and graph.
11. Describe what happens to y when x increases by 1 in your rule.
