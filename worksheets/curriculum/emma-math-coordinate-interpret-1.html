Plot & Interpret Coordinates

Emma · Math
Directions: Use graph paper or draw a coordinate plane. Label axes and every point clearly. When a question says explain, write the answer and one reason using the signs, axes, or coordinate order.

Read the signs

1. Write quadrant or axis for A(3,4), B(-2,5), C(-4,-1), D(6,-3), E(0,5), F(-7,0).
2. Write where each point moves from the origin (left/right and up/down), then write one sentence explaining why the two ordered pairs land in different places.

Plot and interpret

3. Plot P(-5,2), Q(4,3), R(3,-4), and S(-2,-5). Label every point.
4. Name every plotted point below the x-axis. Then state the coordinate clue you used: its y-value is negative.
5. Write one point in Quadrant II. Then write its sign pattern as (negative, positive).
6. Write one point on the x-axis and one point on the y-axis. Then write one sentence explaining that an axis point has x=0 or y=0, so it is not inside a quadrant.

Routes and situations

7. A robot travels (0,0) → (4,0) → (4,-3) → (-2,-3). Plot and describe every move.
8. A fountain is (-3,2), a bench is (2,2), and a gate is (2,-4). Which locations share a y-coordinate and what does that mean?
9. Correct the movement for (-6,1). Then write the x-then-y rule in one sentence: x tells left/right first, and y tells down/up second.

Create

10. Create four points, one in each quadrant, that form a rectangle. Plot and list them.
11. Write a mystery-point clue using quadrant, x, and y so exactly one point can be identified.
