Plot & Interpret Coordinates

Emma · Math
Directions: Use the printed coordinate planes when a question asks you to plot, trace a route, or create a shape. Label every point. For written explanations, name the sign, axis, or coordinate-order fact you used.

Read the signs

1. Write quadrant or axis for A(3,4), B(-2,5), C(-4,-1), D(6,-3), E(0,5), F(-7,0).
2. Write where each point moves from the origin (left/right and up/down), then explain why switching x and y can land in a different place.

Plot and interpret

3. Plot P(-5,2), Q(4,3), R(3,-4), and S(-2,-5). Label every point.
Points below the x-axis: ______________________________________
4. Using your graph from #3, explain the coordinate clue that tells you a point is below the x-axis.
5. Write one point in Quadrant II and its sign pattern.
6. Write one point on the x-axis and one on the y-axis. Explain why axis points are not inside a quadrant.

Routes and situations

7. Plot the robot route (0,0) → (4,0) → (4,-3) → (-2,-3). Draw arrows between stops, then describe every move.
8. Fountain (-3,2), bench (2,2), gate (2,-4): which locations share a y-coordinate and what does that mean?
9. Correct the movement for (-6,1). Then write the x-then-y rule in one sentence.

Create

10. Create four points, one in each quadrant, that form a rectangle. Plot and label them, then list the four ordered pairs.
11. Write a mystery-point clue using quadrant, x, and y so exactly one point can be identified.
