Coordinate Plane — Say the Move First

Independent evidence. Translate signs into movement before plotting.

1. Movement table. For each point, write the horizontal move and vertical move: A(−6,4), B(3,−7), C(−2,−5), D(8,2), E(−9,0), F(0,6). Example format: “left 6, up 4.”
2. Reverse translation. Write the ordered pair for each movement: (a) right 5, down 3; (b) left 7, up 2; (c) left 4, down 6; (d) on the x-axis, 8 units left of the origin; (e) on the y-axis, 5 units above the origin.
3. Axis test. For each point, write x-axis, y-axis, origin, or neither: (−4,0), (0,−7), (3,2), (0,0), (8,0). Then write one sentence explaining how zero tells you the answer.
Tracking #
4. Plot after saying the move. Plot P(−5,6), Q(4,3), R(6,−4), S(−3,−5), and T(0,5). Beside the graph, write the move script and quadrant/axis for each point.
5. Diagnose the mistake. A student says (−4,6) means “right 4, up 6.” Explain exactly which rule is wrong and give the correct movement and quadrant. Then do the same for (5,−3) if a student says “left 5, down 3.”
Tracking #
6. Route tracking. Start at (0,0). Move left 4, up 5, right 7, down 9, left 2. Record the ordered pair after every move and give the final point and quadrant.
7. Mystery points. (a) A point is in Quadrant III with |x|=5 and |y|=2. Write the point and move script. (b) A point is on the y-axis 7 units below the origin. Write the point and explain why its x-coordinate must be zero. (c) A point is in Quadrant II, 3 left and 8 up. Write the point.
8. Rectangle transfer. Plot A(−4,3), B(4,3), C(4,−2), D(−4,−2). Without measuring the picture, find the horizontal side length and vertical side length by comparing coordinates. Explain which coordinate stays the same on a horizontal side and which stays the same on a vertical side.
9. Explain the rule. In 3–4 sentences, explain how you can look at an ordered pair and know the two movement directions, the quadrant, and whether a zero places the point on an axis.
