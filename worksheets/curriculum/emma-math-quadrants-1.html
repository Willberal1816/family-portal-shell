Coordinate Plane: Four Quadrants

Emma · Math

Mini Lesson

The axes divide the plane into four quadrants. Positive x is right, negative x is left; positive y is up, negative y is down. The sign pair tells which quadrant contains the point.

Practice

1. Name the quadrant containing (4, 3).
2. Name the quadrant containing (-5, 2).
3. Name the quadrant containing (-2, -6).
4. Name the quadrant containing (7, -4).
5. Plot or sketch A=(-3,4), B=(2,-5), C=(-4,-2), and D=(5,3).
6. What is special about a point whose x-coordinate is 0?
