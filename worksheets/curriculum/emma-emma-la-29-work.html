Fictional classroom source packet — What Can a Trail Note Say?. Source A — crew record: “West trail closed July 7; boards replaced July 8; trail inspected July 9.” Source B — visitor alert: “Use the south path during the west-trail closure.” Source C — map key listing trail colors.

1. For each of Sources A, B and C, write its purpose in one short phrase.
2. Copy two EXACT dated facts from Source A. Keep the original verbs and number words.
3. Write one exact visitor instruction or access fact from Source B.
4. Which source would answer a repair-date question? Which would answer a visitor-route question? Explain each choice.
