Write the Situation as One Expression

Emma · Independent Work · show the expression before the value

Name ____________________ Date __________

Directions: For #1–6, write one numerical expression, label what its parts mean, then evaluate. Use parentheses only when the story groups actions.
  1. Six shelves hold 9 books each. A cart holds 14 more books.
  2. Four campers each pack 3 shirts and 2 pairs of socks.
  3. A baker makes 5 trays of 12 rolls and gives away 8 rolls.
  4. Twenty-four markers are shared equally among 6 tables, then each table receives 3 more markers.
  5. Write a story for 7 × (4 + 2).
  6. Write a story for 7 × 4 + 2. Make the difference from #5 clear.

Check, repair, create

  1. A student writes 3 × 8 + 5 for “three boxes each contain 8 pencils and 5 erasers.” Repair the expression and explain.
  2. Evaluate 9 + 4 × 6 − 5. Show the order used.
  3. Create two expressions using 6, 3, and 2 that have different values. Explain what changed.
  4. Create a real situation that must use parentheses. Write the expression, value, and one sentence explaining the grouping.
Turn-in check: every number has a meaning; every action has an operation; all requested parts are complete.
